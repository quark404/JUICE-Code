# 机器人轨迹数据集

用于登记包含视觉观测、任务指令和连续动作的数据来源，Robot State 按数据集实际情况可选。用于 Action Policy、World Model 和 V/L/A 联合训练。

以下为前期讨论涉及的候选，不代表已确定纳入、下载或完成接入。

| 数据集 | 来源 / 获取说明 | 拟定用途 | 接入状态 |
|---|---|---|---|
| Open X-Embodiment（OXE） | 多来源机器人轨迹集合，具体子集待确定 | 多来源动作预训练 | 待确定 |
| DROID | 来源、版本与获取方式待登记 | 真实机器人动作与视觉动态 | 待确定 |
| LIBERO | 数据版本与任务划分待登记 | 初步训练与仿真评估 | 待确定 |

确定来源后，在此补充动作类型/维度、是否提供 State、下载地址和存储位置。OXE 与单独引入的数据集可能重叠，需按所选版本核对。
