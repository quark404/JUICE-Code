| BLIP3o 图文数据 | [原仓库数据说明](../DATA.md) | 图文连续表征建模 | 候选，具体子集待确定 |
| 视频与描述数据 | 待补充 | 动态理解与未来视觉预测 | 待调研 |
| 计划 / Subtask 标注 | 待补充，或来自所选机器人轨迹 | Language Planning | 待调研 |

具体数据集、版本、下载地址和存储位置后续在此维护；视频或文本本身不视为可执行 Action 标签。
